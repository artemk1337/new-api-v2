# Инструкция по подключению API-ключей

Эта инструкция помогает выпустить API-ключ, подключить шлюз к Claude Code и настроить приложения, совместимые с OpenAI API. Команды установки и переменные окружения актуализированы по официальным разделам [Setup](https://code.claude.com/docs/en/setup), [Authentication](https://code.claude.com/docs/en/authentication) и [Environment variables](https://code.claude.com/docs/en/env-vars).

> **Безопасность ключа.** Токен вида `sk-xxxxxxxx` — это пароль. Не публикуйте его в чатах, репозиториях, скриншотах и файлах, доступных другим пользователям. В примерах ниже используется только заглушка.

<h2 id="quick-start" class="scroll-mt-24">Быстрый старт</h2>

1. Зарегистрируйтесь на [панели](https://vibecode-api.online). Если вход через GitHub включён, можно использовать его вместо пароля.
2. Пополните баланс через **Кошелёк** доступным для вашего аккаунта способом.
3. В разделе **Ключи API** создайте токен и сохраните его в надёжном месте.
4. Выберите правильный базовый URL:

   | Клиент                                                                                          | Base URL                                  |
   | ----------------------------------------------------------------------------------------------- | ----------------------------------------- |
   | Claude Code / Claude CLI                                                                        | `https://vibecode-api.online` (без `/v1`) |
   | Cursor, Cline, Roo Code, Continue, Open WebUI, Cherry Studio и другие OpenAI-compatible клиенты | `https://vibecode-api.online/v1`          |

5. **Для Claude Code обязательно сначала настройте CLI:** задайте `ANTHROPIC_AUTH_TOKEN` и `ANTHROPIC_BASE_URL`, запустите `claude` и отправьте в CLI минимум один запрос. Дождитесь успешного ответа.
6. Только после первого успешного запроса в CLI открывайте приложение или интеграцию Claude Code — она подхватит подготовленную конфигурацию.
7. Для OpenAI-compatible приложения укажите API Key и проверьте доступ к `/v1/models`.

Если нужен только Claude Code, переходите к разделу [«Установка Claude Code CLI»](#claude-code-install). Для Cursor, Cline и других клиентов используйте раздел [«OpenAI-compatible приложения»](#openai-compatible).

> **Не путайте адреса.** Claude Code использует Anthropic-совместимые переменные и адрес без `/v1`. OpenAI-compatible клиенты ожидают endpoint `/v1/chat/completions`, поэтому им нужен адрес с `/v1`.

> **Главное для Claude Code.** Одной установки CLI и сохранения ключа недостаточно. Сначала сделайте хотя бы один успешный запрос именно из терминального CLI `claude`. После этого можно закрыть CLI и открыть приложение или интеграцию Claude Code — конфигурация будет готова к работе.

<h2 id="initial-setup" class="scroll-mt-24">1. Первичная настройка</h2>

1. Откройте [панель](https://vibecode-api.online/), зарегистрируйтесь или войдите.
2. Откройте **Кошелёк** и выберите доступный способ пополнения. Набор способов зависит от текущих настроек сервиса и может включать СБП, банковскую карту, криптовалюту, ручной перевод или бонусный код.
3. Откройте вкладку **Ключи API**.
4. Создайте новый API-ключ. Если доступен выбор группы, выберите подходящую группу или `auto`. В режиме `auto` шлюз выбирает доступную группу по правилам маршрутизации и при необходимости повторяет запрос в другой группе.
5. Скопируйте токен и сохраните его в менеджере паролей. Не добавляйте пробелы или переносы строк и не используйте один ключ совместно с другими людьми.
6. При необходимости ограничьте токен сроком действия, квотой, доступными моделями и IP-адресами. Для разных устройств и приложений удобнее выпускать отдельные ключи: так проще отозвать один ключ без остановки остальных. Ограничения частоты запросов задаются сервером для группы и не настраиваются в отдельном ключе.

<h2 id="claude-code-install" class="scroll-mt-24">2. Установка Claude Code CLI</h2>

### macOS, Linux и WSL

#### 2.1. Рекомендуемый способ: нативный установщик

Нативная установка не требует Node.js и обновляется автоматически. Выполните в системном терминале:

```shell
curl -fsSL https://claude.ai/install.sh | bash
```

Команда загружает и сразу запускает установочный скрипт. Проверяйте домен `claude.ai`; в корпоративной среде сначала сохраните и изучите скрипт согласно правилам безопасности. На macOS можно вместо этого установить стабильный канал через `brew install --cask claude-code` — Homebrew-установка обновляется вручную командой `brew upgrade claude-code`.

После установки откройте новый терминал и проверьте CLI:

```shell
claude --version
claude doctor
```

Если команда `claude` не найдена, добавьте `~/.local/bin` в `PATH` по подсказке установщика и снова откройте терминал.

**Альтернатива через npm:** используйте её только если нативная установка недоступна. Для актуального npm-пакета нужен Node.js 22 или новее:

```shell
npm install -g @anthropic-ai/claude-code@latest
```

Не запускайте установку через `sudo npm install -g`: это часто приводит к проблемам с правами.

#### 2.2. Переменные окружения

Для zsh на macOS задайте переменные один раз, затем откройте новый терминал:

```shell
echo 'export ANTHROPIC_AUTH_TOKEN="sk-xxxxxxxx"' >> ~/.zshrc
echo 'export ANTHROPIC_BASE_URL="https://vibecode-api.online"' >> ~/.zshrc
echo 'export CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC="1"' >> ~/.zshrc
source ~/.zshrc
```

Для bash:

```shell
echo 'export ANTHROPIC_AUTH_TOKEN="sk-xxxxxxxx"' >> ~/.bashrc
echo 'export ANTHROPIC_BASE_URL="https://vibecode-api.online"' >> ~/.bashrc
echo 'export CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC="1"' >> ~/.bashrc
source ~/.bashrc
```

#### 2.3. Альтернатива: `~/.claude/settings.json`

Используйте файл, если переменные окружения не подхватываются или удобнее хранить настройки Claude Code в одном месте. Файл содержит секрет: не добавляйте его в репозиторий и ограничьте к нему доступ.

```shell
mkdir -p ~/.claude
cd ~/.claude
touch settings.json
chmod 600 settings.json
```

Откройте `settings.json` в редакторе: на macOS можно выполнить `open settings.json`, а в Linux — использовать привычный редактор.

Пример содержимого (замените только значение токена):

```json
{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "sk-xxxxxxxx",
    "ANTHROPIC_BASE_URL": "https://vibecode-api.online",
    "CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC": "1"
  }
}
```

> `CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC=1` отключает телеметрию, отчёты об ошибках и автоматические обновления. При такой настройке периодически запускайте `claude update`. `API_TIMEOUT_MS` по умолчанию равен 600000 мс (10 минут), поэтому добавляйте его только если действительно нужен другой таймаут. `CLAUDE_CODE_DISABLE_EXPERIMENTAL_BETAS=1` используйте только при подтверждённой несовместимости шлюза с beta-заголовками: этот флаг отключает часть возможностей Claude Code.

Команды `cd`, `touch` и редактирование файла выполняются в системном терминале, а не внутри Claude Code. После запуска подтвердите доверие к папке проекта. Если появится `Auth Conflict`, не игнорируйте его: оставьте только `ANTHROPIC_AUTH_TOKEN` и удалите `ANTHROPIC_API_KEY` из окружения или настроек.

### Windows

1. Откройте PowerShell.
2. Установите Claude Code: `winget install Anthropic.ClaudeCode`.
3. Проверьте установку командами `claude --version` и `claude doctor`.
4. После изменения постоянных переменных через `setx` полностью закройте терминал и откройте новый.

Если WinGet недоступен, используйте официальный PowerShell-установщик:

```powershell
irm https://claude.ai/install.ps1 | iex
```

Постоянные переменные через Command Prompt:

```bat
setx ANTHROPIC_AUTH_TOKEN "sk-xxxxxxxx"
setx ANTHROPIC_BASE_URL "https://vibecode-api.online"
setx CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC "1"
```

Только текущая сессия PowerShell:

```powershell
$env:ANTHROPIC_AUTH_TOKEN="sk-xxxxxxxx"
$env:ANTHROPIC_BASE_URL="https://vibecode-api.online"
$env:CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC="1"
claude
```

Чтобы сохранить переменные из PowerShell для следующих сессий без `setx`, можно использовать `[Environment]::SetEnvironmentVariable('ANTHROPIC_AUTH_TOKEN', 'sk-xxxxxxxx', 'User')` и аналогично задать `ANTHROPIC_BASE_URL`. После этого откройте новый терминал.

<h2 id="claude-code" class="scroll-mt-24">3. Claude Code</h2>

> **Обязательная последовательность:** сначала полностью настройте Claude Code CLI, затем отправьте через CLI минимум один запрос и дождитесь ответа. Только после этого переходите к приложению или интеграции Claude Code.

1. Выполните установку и настройку переменных из предыдущего раздела.
2. Откройте папку проекта в системном терминале.
3. Запустите CLI:

   ```shell
   claude
   ```

4. Подтвердите доверие к папке и отправьте простой проверочный запрос, например: `Ответь одним словом: работает`.
5. Убедитесь, что модель успешно ответила. Ошибка авторизации, повторные попытки или зависший запрос не считаются успешной настройкой.
6. Теперь CLI можно закрыть и открыть приложение или интеграцию Claude Code — она подхватит подготовленную конфигурацию.

Конфигурация из переменных окружения или `~/.claude/settings.json` применяется к CLI и интеграциям, которые используют Claude Code CLI. Claude Desktop и облачные сессии на сайте не обязаны использовать эти настройки.

При первом запуске Claude Code попросит подтвердить доверие к папке проекта. Проверяйте путь: доверяйте только каталогам, содержимое которых вы понимаете.

> **Опасный режим.** `--dangerously-skip-permissions` отключает интерактивные подтверждения команд. Используйте его только в доверенной папке, не храните там секреты и проверяйте команды перед запуском.

Для доверенной папки проекта можно уменьшить число подтверждений:

```shell
claude --dangerously-skip-permissions
```

Не сохраняйте этот флаг в глобальный alias: иначе опасный режим легко запустить в случайной папке.

Модель можно сменить командой `/model`. В свежих версиях Claude Code список моделей совместимого шлюза можно загрузить из `/v1/models` с помощью `CLAUDE_CODE_ENABLE_GATEWAY_MODEL_DISCOVERY=1`. Сначала обновите CLI и проверьте, что переменная поддерживается вашей версией. Не включайте её на общем ключе, если список моделей не должен быть виден всем его пользователям.

<h2 id="openai-compatible" class="scroll-mt-24">4. OpenAI-compatible приложения</h2>

Выберите провайдера **OpenAI Compatible**, укажите Base URL **с `/v1`** и вставьте API Key. Одного ключа недостаточно: без Base URL приложение может обратиться к своему серверу по умолчанию.

Примеры клиентов: Cursor, Cline, Roo Code, Continue.dev, Open WebUI, Cherry Studio, OpenHands и Aider. Названия и расположение полей зависят от версии конкретного приложения.

**Base URL:** `https://vibecode-api.online/v1`

Пример Continue.dev:

```yaml
models:
  - title: Claude через API-шлюз
    provider: openai
    model: MODEL_ID_FROM_V1_MODELS
    apiBase: https://vibecode-api.online/v1
    apiKey: sk-xxxxxxxx
```

Точный model ID возьмите из ответа `/v1/models` или из списка моделей в диалоге создания/редактирования ключа. Общая административная страница моделей может быть недоступна обычному пользователю.

### Cline, Cursor и другие клиенты

В каждом клиенте проверьте четыре поля: тип провайдера — OpenAI Compatible, Base URL — с `/v1`, API Key — токен `sk-...`, Model — точный `id` из `/v1/models`. Не угадывайте имя модели и не добавляйте префиксы вручную. Возможность подключить свой endpoint зависит от версии и тарифа самого клиента.

<h2 id="diagnostics" class="scroll-mt-24">5. Проверка ключа и базовая диагностика</h2>

Чтобы ключ не остался в истории shell, сначала прочитайте его в скрытую переменную, затем проверьте список моделей:

```shell
read -s VIBECODE_API_KEY
curl --fail-with-body --silent --show-error \
  https://vibecode-api.online/v1/models \
  -H "Authorization: Bearer ${VIBECODE_API_KEY}"
unset VIBECODE_API_KEY
```

Это OpenAI-compatible вариант с `Authorization: Bearer`. Для проверки Anthropic-совместимой авторизации используйте тот же endpoint с заголовками Claude API:

```shell
read -s VIBECODE_API_KEY
curl --fail-with-body --silent --show-error \
  https://vibecode-api.online/v1/models \
  -H "x-api-key: ${VIBECODE_API_KEY}" \
  -H 'anthropic-version: 2023-06-01'
unset VIBECODE_API_KEY
```

| Проверка            | Команда или действие                                                                      | Нормальный результат                                                                           |
| ------------------- | ----------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------- |
| Claude Code         | `claude --version` и `claude doctor`                                                      | Версия выводится, критичных ошибок нет                                                         |
| Claude Code в PATH  | macOS/Linux: `command -v claude`; Windows: `where.exe claude`                             | Один ожидаемый путь; для native install на macOS/Linux обычно `~/.local/bin/claude`            |
| Base URL            | macOS/Linux: `printf '%s\n' "$ANTHROPIC_BASE_URL"`; PowerShell: `$env:ANTHROPIC_BASE_URL` | Для Claude Code: `https://vibecode-api.online`                                                 |
| Доступность моделей | Выполните один из примеров выше с `${VIBECODE_API_KEY}`                                   | OpenAI JSON для Bearer или Anthropic JSON для `x-api-key`                                      |
| Токен и группа      | Панель **Ключи API**                                                                      | Токен активен, срок не истёк, квота не исчерпана, группа и разрешённые модели подходят запросу |

<h2 id="troubleshooting" class="scroll-mt-24">6. Алгоритм решения проблем</h2>

1. Определите слой ошибки: панель и токен, сеть, окружение, Claude Code или конкретный клиент.
2. Сверьте Base URL: без `/v1` для Claude Code, с `/v1` для OpenAI-compatible приложений.
3. Проверьте токен: начало `sk-`, без пробелов, кавычек и переносов строк; срок, квота, группа, список моделей и IP-ограничения должны разрешать запрос.
4. После изменения постоянных переменных откройте новый терминал или перезапустите приложение.
5. Выполните запрос к `/v1/models`. Если он не работает, сначала исправьте адрес, сеть или токен.
6. Для ошибки внутри длинного диалога попробуйте `/compact`, `/exit` или новую сессию. `Esc Esc` используйте, если нужно вернуться к предыдущему сообщению и отредактировать его.
7. Если проблема только в одном проекте, проверьте вторую сессию Claude Code, конфликтующие файлы и права доступа.

<h2 id="error-table" class="scroll-mt-24">7. Таблица ошибок</h2>

| Симптом                                                     | Вероятная причина                                                                     | Что сделать                                                                                                                                          |
| ----------------------------------------------------------- | ------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| Claude Code обращается к `api.anthropic.com`                | Не подхватился `ANTHROPIC_BASE_URL`                                                   | Проверьте окружение или `settings.json`, перезапустите терминал                                                                                      |
| `request to https://xxxx failed`                            | Неверный URL или лишний путь                                                          | Claude Code: URL без `/v1`; другие клиенты: URL с `/v1`                                                                                              |
| `Invalid token` или `401 token expired`                     | Неверный или истёкший токен                                                           | Проверьте ключ и срок действия; при необходимости выпустите новый и замените его во всех конфигурациях                                               |
| `403` при корректном ключе                                  | Токену запрещена группа, модель или IP-адрес                                          | Проверьте группу, model allowlist, IP-ограничения и квоту в разделе **Ключи API**                                                                    |
| `Auth conflict: ANTHROPIC_AUTH_TOKEN and ANTHROPIC_API_KEY` | Заданы две переменные авторизации                                                     | Оставьте `ANTHROPIC_AUTH_TOKEN`, удалите `ANTHROPIC_API_KEY`, откройте новый терминал; при необходимости выполните `/logout`                         |
| `Max tokens must exceed thinking budget`                    | `max_tokens` не превышает заданный thinking budget                                    | Увеличьте `max_tokens` или уменьшите/уберите параметр thinking/reasoning в клиенте                                                                   |
| `API Error: retrying` / `overloaded_error`                  | Сеть, прокси или перегрузка сервера                                                   | Проверьте `/v1/models`, прокси, подождите и начните новую сессию                                                                                     |
| `tool_call_error`, `400 tool_result`                        | Повреждено состояние диалога или несовместимые beta-заголовки                         | Повторите запрос; затем начните новую сессию. Только если ошибка подтверждённо связана со шлюзом, задайте `CLAUDE_CODE_DISABLE_EXPERIMENTAL_BETAS=1` |
| `npm WARN EBADENGINE` при установке                         | Для npm-пакета используется Node.js ниже 22                                           | Используйте нативный установщик или обновите Node.js до 22+                                                                                          |
| `File has been unexpectedly modified`                       | Две сессии меняют один проект                                                         | Закройте лишнюю сессию и используйте абсолютные пути в Windows                                                                                       |
| `ECONNRESET Retrying`                                       | Соединение сброшено сетью, прокси или сервером                                        | Повторите `/v1/models`, проверьте сеть и только затем настройки прокси; JSON-файл сам по себе обычно не вызывает сброс TCP-соединения                |
| Нужной модели нет в списке                                  | Модель недоступна группе токена, запрещена allowlist/mapping или выключена на сервере | Сверьте `/v1/models`, группу и ограничения ключа; обновление CLI само по себе не добавляет модели на сервер                                          |
| `/v1/models` работает, приложение нет                       | Ошибка в provider, model ID, Base URL или формате авторизации                         | Сверьте четыре поля; `/v1` нужен OpenAI-compatible клиенту и не нужен в `ANTHROPIC_BASE_URL`                                                         |

<h2 id="commands" class="scroll-mt-24">8. Полезные команды Claude Code</h2>

| Команда                                 | Назначение                                             |
| --------------------------------------- | ------------------------------------------------------ |
| `claude`                                | Запустить интерактивную сессию                         |
| `claude --dangerously-skip-permissions` | Запуск без лишних подтверждений в доверенной папке     |
| `claude update`                         | Обновить Claude Code                                   |
| `claude doctor`                         | Проверить установку, PATH и обновления                 |
| `claude --continue` (`-c`)              | Продолжить последнюю сессию в текущей папке            |
| `claude --resume` (`-r`)                | Выбрать сессию из списка или продолжить её по ID/имени |
| `/exit`                                 | Выйти из сессии                                        |
| `/model`                                | Посмотреть или переключить модель                      |
| `/compact`                              | Сжать контекст диалога                                 |
| `/logout`                               | Сбросить авторизацию при конфликте ключей              |

<h2 id="hotkeys" class="scroll-mt-24">9. Горячие клавиши</h2>

| Клавиши   | Действие                                         |
| --------- | ------------------------------------------------ |
| `Ctrl+C`  | Отменить ввод или генерацию                      |
| `Ctrl+D`  | Выйти из сессии                                  |
| `Ctrl+L`  | Очистить экран терминала                         |
| `↑` / `↓` | Навигация по истории команд                      |
| `Esc Esc` | Вернуться к предыдущему сообщению и изменить его |
| `Tab`     | Автодополнение команд и путей                    |

<h2 id="context" class="scroll-mt-24">10. Как не потерять контекст</h2>

Для длинной задачи попросите Claude Code вести `todo.md` или `plan.md` с целью, шагами, статусом и решениями. Перед `/compact` сохраните важные требования в файл. После сбоя запускайте новую сессию и просите продолжить по этому файлу.

<h2 id="faq" class="scroll-mt-24">11. FAQ</h2>

| Вопрос                                                    | Ответ                                                                                                                                                                                 |
| --------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Можно ли вставить бонусный код вместо API-ключа?          | Нет. Если бонусные коды доступны, код применяется только в **Кошельке**. В приложение вставляется токен `sk-...`.                                                                     |
| Почему Claude Code использует URL без `/v1`?              | Он работает через Anthropic-совместимые переменные и корневой URL шлюза.                                                                                                              |
| Почему Cursor/Cline требуют `/v1`?                        | Они вызывают OpenAI-compatible endpoints, например `/v1/chat/completions`.                                                                                                            |
| Что выбрать: окружение или `settings.json`?               | Окружение проще для одной сессии; `~/.claude/settings.json` удобнее для постоянной настройки. Оба варианта хранят секрет локально, поэтому ограничьте доступ к файлам и устройству.   |
| Что делать, если `/v1/models` работает, а приложение нет? | Сверьте provider, Base URL и точный model ID. Для OpenAI-compatible клиента проверьте Bearer-токен, для Anthropic-клиента — `x-api-key`/`ANTHROPIC_AUTH_TOKEN` и `anthropic-version`. |
| Почему после установки через npm появляется `EBADENGINE`? | Актуальный npm-пакет требует Node.js 22+. Проще перейти на нативный установщик, которому Node.js не нужен.                                                                            |
| Можно ли запускать две сессии в одном проекте?            | Не рекомендуется: они могут одновременно менять файлы.                                                                                                                                |
| Как обратиться в поддержку?                               | Передайте тип клиента, Base URL, текст ошибки и результат без реального токена.                                                                                                       |
| Что делать при утечке токена?                             | Немедленно удалите или перевыпустите ключ в панели и замените его везде.                                                                                                              |
| Нужен ли прокси?                                          | Обычно нет. `HTTP_PROXY`/`HTTPS_PROXY` задавайте только для известного вам прокси и порта.                                                                                            |

<h2 id="support-checklist" class="scroll-mt-24">12. Чек-лист перед обращением за помощью</h2>

<h2 id="compatible-apps" class="scroll-mt-24">13. Совместимые приложения</h2>

Claude Code CLI подключается через Anthropic Messages API. Cursor, Cline, Roo Code, Continue.dev, Cherry Studio, Open WebUI, OpenHands, Aider и другие клиенты могут подключаться через OpenAI Compatible API, если их версия позволяет указать собственный Base URL и API Key.

<h2 id="url-reference" class="scroll-mt-24">14. Шпаргалка по URL</h2>

| Сценарий                    | URL                                               | Примечание                                                                  |
| --------------------------- | ------------------------------------------------- | --------------------------------------------------------------------------- |
| Claude Code: Base URL       | `https://vibecode-api.online`                     | Указывайте корень без `/v1`; CLI сам вызывает Anthropic endpoints           |
| Anthropic Messages API      | `https://vibecode-api.online/v1/messages`         | Обычно клиент формирует этот путь сам                                       |
| OpenAI-compatible: Base URL | `https://vibecode-api.online/v1`                  | Для клиентов с отдельным полем Base URL                                     |
| OpenAI Chat Completions     | `https://vibecode-api.online/v1/chat/completions` | Используйте полный адрес, только если клиент просит endpoint, а не Base URL |
| OpenAI Responses API        | `https://vibecode-api.online/v1/responses`        | Для клиентов с поддержкой Responses API                                     |
| Список моделей              | `https://vibecode-api.online/v1/models`           | Поддерживает Bearer и Anthropic-style авторизацию                           |
